# Support

The supported protocol line is Schemami v1. The latest `1.x` release receives
correctness and security fixes; pre-publication RCP formats are unsupported and
are refused explicitly.

Use GitHub issues for reproducible bugs, documentation gaps, and narrowly scoped
feature proposals. Include the Schemami version, SDK/language version, exact
operation, and stable problem type/pointer when available. Do not attach private
recipe sources, credentials, or personal information.

Questions about an application's mappings, translations, UI, storage, AI
provider, OCR, or culinary policy belong to that application, not the Schemami
protocol.
