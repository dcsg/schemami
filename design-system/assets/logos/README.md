# Logo assets

Canonical Schemami Identity A exports.

- `schemami-lockup-*` — outlined horizontal signatures.
- `schemami-wordmark-*` — outlined wordmark without the symbol.
- `schemami-mark-*` — transparent masters and the Page tile.
- `schemami-icon-16|24|32` — optically adjusted small-size tiles.

Use rules, clear space, minimum sizes and approved backgrounds are defined in
[`docs/brand/schemami-identity-standard.md`](../../../docs/brand/schemami-identity-standard.md).

The wordmark paths are generated by
[`scripts/build-brand-assets.py`](../../scripts/build-brand-assets.py). Do not
edit generated path data or recreate the lockup with SVG `<text>`.
