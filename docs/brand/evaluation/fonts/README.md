# Evaluation fonts

These files exist only to render the Schemami identity challenger board with
the real proposed fonts. They are not a production font package or an approved
subset plan.

Downloaded 10 August 2026 with `npm pack`:

| Package | Version | Files used |
|---|---:|---|
| `@fontsource-variable/fraunces` | 5.3.0 | Latin and Latin Extended full variable Roman |
| `@fontsource-variable/recursive` | 5.3.0 | Latin and Latin Extended full variable Roman |
| `@fontsource/ibm-plex-sans` | 5.3.0 | Latin Roman 400, 500 and 600 |
| `@fontsource/ibm-plex-mono` | 5.3.0 | Latin Roman 400 and 600 |

The corresponding license texts are in [`licenses/`](licenses/). The approved
production subset package is now maintained separately under
[`design-system/assets/fonts`](../../../../design-system/assets/fonts); do not
promote files from this evaluation folder into an application.

Official sources:

- <https://github.com/undercasetype/Fraunces>
- <https://github.com/arrowtype/recursive>
- <https://github.com/IBM/plex>
